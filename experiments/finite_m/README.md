# Finite-dimensional ranking sweep

This experiment compares the exact finite-dimensional Beta–arcsine law with
its leading small-`m/d` approximation and records the fixed-candidate
Gaussian-score nearest-neighbor limit.

```bash
python experiments/finite_m/run.py --d 400 --q 8 --output artifacts/finite_m.csv
```

Use the output to decide whether an asymptotic slogan is accurate enough at
the dimensions of a concrete application.
